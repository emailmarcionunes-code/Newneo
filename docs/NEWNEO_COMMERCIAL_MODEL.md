# Newneo Commercial Model

## Revenue structure
Newneo should combine:
- Assessment
- POC / first use case
- Deployment Engineering
- recurring Newneo AI Platform subscription
- variable usage
- optional Managed AgentOps
- training when applicable

## Platform principle
Production agents should normally remain under the Newneo AI Platform so lifecycle, governance, evaluation, deployment, audit and AgentOps stay controlled in one place.

## Consumption principle
Do not make agent count the primary consumption unit.

Agents organize work. Tasks represent work performed.

A Newneo Task is one business request carried to a terminal outcome, even when it requires multiple internal model calls, knowledge lookups, actions or approvals.

Track at minimum:
- tasks started
- successful tasks
- escalations
- cost per task
- cost per successful task
- business outcome when measurable

## AI Units
Different tasks may require very different levels of compute, tool use and reasoning. Newneo may normalize these differences into AI Units so customer billing remains understandable while internal cost accounting remains accurate.

## Unit economics
For each task, measure the underlying model, retrieval, tool, compute, storage, telemetry and allocated operating cost.

AgentOps should expose enough economics to answer:
**What value is production AI creating relative to what it costs?**

## Growth principle
Do not discourage customers from adding useful agents with a rigid per-agent fee model.

Commercial growth should come from platform adoption, useful task volume, additional deployments and optional managed operations.
