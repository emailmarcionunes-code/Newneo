# Newneo Employee Study Guide

## The customer story
A customer starts with a business process, not with an infrastructure product.

Newneo onboards the organization, understands its environment, policies, systems, identity, data boundaries and deployment requirements, and then helps launch the first production agent.

The guided path is:
`Use Case → Knowledge → Tools → Model & Runtime → Governance → Evaluate → Deploy → Operate`

The agent can run in Newneo SaaS, the customer cloud, a private environment or a hybrid architecture. The customer experience stays consistent across these deployment choices.

Before production, Newneo evaluates the agent against business, quality, tool and policy criteria. Production promotion is controlled and auditable.

Once live, AgentOps begins showing task success, escalation, quality, operating cost and business outcomes. The customer sees value appear as real work is completed.

The expansion story is:
`Deploy → Operate → Expand`

Start with one agent, prove value, reuse the foundation and expand across the enterprise.

## How to explain agents and tasks
Agents are organizational objects. Tasks are economic objects.

The number of agents is not the primary measure of customer consumption. A few agents can perform enormous volumes of work, while many agents may have light usage.

A task is one business request taken to a terminal outcome, even if it requires several model calls, knowledge lookups, tool calls or approvals.

## Reusable intelligence
Newneo can use open standards, public patterns and third-party components, but the product advantage is not simply owning a large list of skills.

The Newneo value stack is:
`Public Skill → Hardened Skill → Enterprise Pattern → Proven Intelligence → Operational System`

Over time, Newneo accumulates reusable skills, evaluations, governance patterns, operating methods and deployment knowledge.

Customer-specific information remains customer-specific. Generalized improvements to the Newneo platform, methods and reusable intelligence become Newneo reusable intellectual property.

## Core principle
**Skills are ingredients. Newneo is the operating system.**

The long-term asset is the combination of platform, reusable intelligence, evaluations, governance, operational history and AgentOps knowledge.
