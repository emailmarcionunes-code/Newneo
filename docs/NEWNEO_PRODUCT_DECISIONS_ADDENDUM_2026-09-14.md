# Newneo Product Decisions Addendum — 2026-09-14

This addendum records product decisions that complement the main AI Platform specification.

## 1. Customer lifecycle story
The operating story is:
`Onboard → Deploy First Agent → Operate → Prove Value → Expand`

Newneo should reuse information collected during discovery, assessment and POC so the customer does not start from zero inside the AI Platform.

The first agent follows:
`Use Case → Knowledge → Tools → Model & Runtime → Governance → Evaluate → Deploy → Agent Detail → AgentOps`

## 2. Platform is the production control layer
Newneo production agents should normally remain under the Newneo AI Platform so governance, evaluation, versioning, deployment, audit and AgentOps remain controlled.

## 3. Agents versus tasks
The number of agents is not the main economic unit.

Agents organize work. Tasks represent work performed.

A task is one business request carried to a terminal outcome, even when it contains multiple internal model calls, retrievals, tool actions or approvals.

AgentOps should support task economics including cost per task, cost per successful task and business outcome when measurable.

## 4. Skills strategy
A skill library alone is not the moat because skills and agent components can be shared across ecosystems.

Newneo value stack:
`Public Skill → Hardened Skill → Enterprise Pattern → Proven Intelligence → Operational System`

Newneo should maintain skill maturity states such as:
`Experimental → Validated → Production Ready → Proven at Scale`

The long-term asset is Newneo Enterprise AI Operating Intelligence: reusable skills, enterprise patterns, evaluations, governance, deployment knowledge, operational history and economics.

## 5. Intellectual property boundary
Customer-specific data, confidential information, business content, policies and credentials remain customer-specific.

Newneo retains its platform and reusable intellectual property, including generalized skills, templates, methods, evaluation frameworks, governance patterns, deployment automation, AgentOps methods and generalized improvements.

Generalized operational learning may improve Newneo across customers only when it does not disclose or transfer customer confidential information.

## 6. Exit principle
Leaving Newneo should be possible without transferring ownership of the Newneo platform.

Customers should be able to receive applicable customer data and agreed customer-specific artifacts. Reusable Newneo IP remains Newneo property.

Private deployments should support a controlled transition state at contract end rather than destructive shutdown behavior.

## 7. Global contract model
Target commercial/legal structure:
- Global Master Services Agreement
- Order Form
- Platform Terms
- Data Processing Addendum
- Security / service schedules
- jurisdiction-specific schedules where required
- Statement of Work for project-specific services

Final legal language requires qualified counsel in the applicable jurisdictions.

## 8. Commercial architecture
Commercial layers:
- Assessment
- POC / first use case
- Deployment Engineering
- recurring Platform subscription
- variable usage / AI Units
- optional Managed AgentOps
- training when applicable

Avoid a rigid primary per-agent charge that discourages enterprise expansion.

## 9. Product moat
The product moat is not closed access to basic skills.

The moat is the operating system around enterprise AI: deployment, hardened reusable intelligence, governance, evaluations, operational evidence, task economics and continuous improvement.

Core phrase:
**Skills are ingredients. Newneo is the operating system.**
