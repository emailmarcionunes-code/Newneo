# Three-step Add Agent journey

The primary catalog flow is now Select → Understand → Accept & add. Small cards show a concise summary and Learn more; the entire card links to the same detail page. The details retain skills, context, infrastructure, model requirements, governance and evaluation behind compact panels and expandable sections.

Confirmation allows renaming and requires explicit acceptance. It saves the recommended profile directly through the existing workspace-scoped registry API, pins latest available matching Skill versions and links available matching documents. Optional/high-risk skills and archived records are excluded. Execution is not activated. Demo additions use isolated preview state without fabricated evaluation or deployment events.

Validation: platform production build and two focused persistence/binding tests passed. Hosted visual verification uses an isolated demo session; the GAW session expired and requires a fresh login. No test Agent is added to GAW.
